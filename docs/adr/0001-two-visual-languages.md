# 日报与追问采用两套视觉语言

日报与频道使用编辑风（暖纸底、强字重层级、卡片、中文系统粗体标题 + 压缩体数字），追问使用近单色的工具风（黑气泡、大留白、底部 `+`/输入框/麦克风三件套，参照 Grok Bot）。

这是有意的分裂而非疏漏。两者被读的方式不同：日报是被逐段读过去的长内容，需要版面、层级与辨识度；追问是短回合的工具型对话，需要的是把注意力放在气泡上而不是装饰上。统一成一套会让日报显得像聊天记录，或让追问显得像文档。

代价是两套颜色、间距与圆角刻度并存。缓解办法是把两者都收敛进语义 token（`canvas` / `surface` / `primaryText` / …），并在实现时按界面归属选 token 组，而不是在视图里写字面色值。

**放弃的方案**：整体跟随 Grok Bot（日报失去版面感）；整体保留编辑风（追问会像一张卡片列表，输入区也没有合适的位置）。
